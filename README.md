# AI知识助手后端系统
基于Spring Boot 3 + 字节跳动豆包大模型的轻量RAG知识库系统，支持文档上传、向量检索、智能问答、多轮对话。

## 🎯 项目简介
本项目是一个完整的AI知识助手后端系统，核心实现了**检索增强生成（RAG）**技术，让大模型能够基于用户上传的私有文档进行精准问答，有效解决大模型幻觉问题。

项目采用标准MVC三层架构开发，实现了完整的用户认证体系、基础工程化能力与Docker容器化部署，是一个可真实运行、代码规范、逻辑完整的Java后端学生项目。

## 🛠️ 技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| Spring Boot | 3.2.5 | 后端核心框架 |
| MyBatis-Plus | 3.5.7 | ORM框架，简化数据库单表CRUD操作 |

## ✨ 核心功能
### 1. 用户认证与权限管理
- 用户注册、登录、登出全生命周期管理
- JWT无状态身份认证，结合ThreadLocal实现全局用户上下文
- BCrypt单向密码加密，保障用户信息安全
- 严格的用户数据隔离，仅可操作自身创建的会话与文档

### 2. 多轮AI对话
- 多会话管理，支持用户创建多个独立对话场景
- 对话上下文关联，AI可基于历史对话内容连续回答
- 对话记录持久化存储，支持历史消息查询
- 基于Sentinel实现接口限流，防止恶意刷接口

### 3. 轻量RAG私有知识库
- 支持TXT文档上传与文本内容提取
- 智能文本分块，避免长文档语义断裂
- 基于豆包多模态Embedding API实现文本向量化
- 余弦相似度计算实现语义检索，预计算向量模长优化90%计算量
- 0.75相似度阈值过滤，无相关内容时明确兜底，减少大模型幻觉
- Redis缓存重复Embedding结果，节省API费用，提升响应速度

### 4. 工程化能力
- 全局统一返回格式与全局异常处理，前后端交互规范
- 基于Spring AOP实现全接口操作日志与耗时统计，500ms慢接口自动告警
- 规范的日志分级打印与滚动输出，方便线上问题排查
- 完整的接口参数校验与边界场景处理
- Docker容器化一键部署，支持多环境配置
